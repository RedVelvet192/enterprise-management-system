# Enterprise Management System

A modular full-stack enterprise management platform.

## Overview

This project aims to develop a scalable enterprise
management system for managing customers, employees,
products, inventory, and sales.

## Technology Stack

- Frontend: React and TypeScript
- Backend: Python and FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy
- Containerization: Docker
- Version Control: Git and GitHub

## Architecture

The application follows a modular architecture
with separated frontend, backend, and database layers.
